### Why Now

1. **Stellar's Soroban** — Smart contracts now cost $0.00001/tx (vs ETH's $2-50)
2. **Mainstream wallets** — Freighter, Albedo widely adopted
3. **USDC adoption** — African platforms now accept stablecoins
4. **Market timing** — Digital Ajo platforms already proven (₦100B moved)

### Competitive Advantage

- **First mover:** No other trustless group savings platform
- **Stellar ecosystem:** Built with their support
- **Unit economics:** $5 CAC, 2-week payback = scalable
- **Network effects:** Each group creates 5-10 new users
