# StellarSave Demo Video Script (60 seconds)

## Scene 1: Opening (0-5 seconds)

**Visual:** Show landing page  
**Text on screen:** "StellarSave — Trustless Savings Groups"  
**Voice:** "Meet StellarSave. We're digitizing Africa's $20 billion informal savings market."

---

## Scene 2: Problem (5-15 seconds)

**Visual:** Show problem section on landing page  
**Voice:** 
"Ajo, Esusu, Adashe — call it what you want. 100 million Africans save together in groups. But there's a problem: the collector holds all the cash."

**Text on screen:** 
"22% of groups fail when the collector disappears"

---

## Scene 3: Solution (15-25 seconds)

**Visual:** Transition to app, show interactive demo starting  
**Voice:** 
"What if instead of trusting a person, you trusted math? StellarSave replaces the collector with a smart contract."

**Show the demo flow:**
1. Create group (2 sec)
2. Members contribute (3 sec)
3. Auto payout (2 sec)

**Text on screen:** "No middleman. No fees. Pure blockchain."

---

## Scene 4: Key Features (25-45 seconds)

**Visual:** Walk through features on landing page  
**Voice over:**

"Here's what you get:

✓ **Zero fees** — no platform rake
✓ **Borderless** — works globally via USDC  
✓ **Trustless** — smart contract handles everything
✓ **Instant payouts** — atomic, no delays
✓ **Transparent** — all on Stellar blockchain
✓ **Mobile-first** — works on any device"

---

## Scene 5: Live Demo (45-55 seconds)

**Visual:** Show interactive demo page  
**Voice:**
"Here's the interactive demo. No wallet needed. You can see exactly how it works in four steps."

**Click through demo:**
1. Connect wallet (3 sec narration: "First, users connect their Freighter wallet")
2. Create group (2 sec: "Next, they create a group with their friends")
3. Contribute (2 sec: "Members contribute their fixed amount")
4. Automatic payout (2 sec: "The smart contract automatically sends the pool to the recipient")

---

## Scene 6: Call to Action (55-60 seconds)

**Visual:** Back to landing page, focus on CTA buttons  
**Text on screen:** 
"stellarsave.io  
Try the demo. No wallet required.  
Investing coming soon."

**Voice:**
"Try the interactive demo at stellarsave.io. Or check out the GitHub repo. StellarSave — trustless savings for everyone."

**End frame:** Logo + website URL

---

## Recording Tips

**Length:** Exactly 60 seconds (investors hate long videos)  
**Quality:** 1080p, 60fps  
**Audio:** Clear microphone, no background noise  
**Pacing:** Slightly fast but followable  
**Background:** Your app on screen the whole time  

**Tools:**
- **Screen recording:** OBS Studio (free)
- **Voice:** Audacity (free)
- **Editing:** DaVinci Resolve (free) or CapCut
- **Upload:** YouTube (unlisted link for privacy)
